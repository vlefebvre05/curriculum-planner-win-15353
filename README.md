## About WFA Curriculum Planner

WFA Curriculum Planner is a browser-based planning tool designed for school and education settings. It supports the organization of teaching objectives and academic activities over a structured 39-week period.

The planner is intended for educators and curriculum teams who need a clear way to review long-term academic plans. Its web interface keeps planning accessible from a modern browser while providing a focused workspace for mapping the school year.
